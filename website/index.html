第一次使用

安装后从 Windows 开始菜单打开，按向导选择翻译服务和使用模式。

完整使用说明 ↗

在桌面截图

选择「自动」后，SteamVR 未运行时按 Ctrl + Alt + T 截图并翻译。默认截取主显示器；也可在工作台选择「指定窗口」，只翻译所选应用。

在 SteamVR 截图

自行启动 SteamVR 并连接头显后，「自动」会切换到 VR。Touch / Quest 默认长按左 X 1.5 秒触发截图。继续按到 3 秒可取消。

选择翻译服务

积分账户完整翻译成功一次扣 1 积分。你也可使用自备视觉 API、本机 Codex，或本地 OCR 搭配 Google 翻译。直接翻译截图或手写字时，模型只接收一次请求并返回译文；本地 OCR 则可对照原文。

使用前常见问题

截图和文字会发送到哪里？

本地 OCR 只将识别出的文字交给翻译服务。积分服务的图片和 AI 手写模式会将截图交给服务端，向模型发一次请求并直接返回译文。积分主库在任务结束满 7 天后的定时清理中移除原文和译文。服务商与备份各有保留规则。

游戏截图里哪些文字会被翻译？

优先翻译对白、手写留言、路牌和任务文字，尽量跳过性能监控、按键提示和 Windows 任务栏。相同字幕在画面里出现两次时，会尽量只显示一次。截取网页或文档时，则优先翻译正文。

不戴头显也能使用吗？

可以。在 Windows x64 电脑上选择「桌面」即可一直使用桌面字幕；选择「自动」则会跟随 SteamVR 的连接状态。程序不会为你启动 SteamVR。

安装版和便携 ZIP 怎么选？

安装程序适合从开始菜单启动与原位更新。使用便携版时，把 ZIP 全部解压到可写目录后运行 SteamVrTranslator.exe。更新前请先退出旧版，同一 Windows 用户的原有设置会保留。

怎样检查新版本？

如果正在使用 v0.2.5-preview 或更早版本，请从本页手动下载 v0.2.10-preview。之后可点击工作台左侧导航底部的「检查更新」（窄窗口位于顶部导航右侧），查看当前版本和 GitHub 最新版本。有新版时，点「下载新版」在浏览器下载安装程序，再退出翻译器并安装。如果没有对应的安装程序，可点「查看发布页」。
