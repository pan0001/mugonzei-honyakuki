# 开发者管理后台

`/admin/` 是运营者管理积分的网页。登录后可以查看注册账户数、当前已付订单数及这些订单的实付总额。金额取自订单记录的折后价。退款中的订单和已退款订单从这两项付款统计中扣除。

## 在 Windows 本机试用

安装 .NET 10 SDK 和 PowerShell 7，在项目根目录运行以下命令。

```powershell
pwsh -File tools/start-admin-demo.ps1
```

打开终端显示的 `http://127.0.0.1:5197/admin/`，从同一终端提示的本机文件复制本次口令。每次启动都会创建独立的演示数据库，有 200 和 500 积分两档模拟套餐。试建优惠活动时，折扣方案 ID 可以填写 `cccccccccccccccccccccccccccccccc`。例如，选择 200 积分，填写 4.00 元，确认页会显示原价 5.00 元和折后价 4.00 元。在终端按 Ctrl+C 结束演示。端口已被占用时可添加 `-Port 5198`。

## 配置生产环境

1. 使用带后台页面的服务端构建。HTML、CSS 和 JavaScript 随服务端一起发布。先按[部署说明](deploy/README.md)备份数据库。现有服务端配置文件由系统管理员保管，权限为 `0600`。
2. 在受保护的终端运行 `openssl rand -hex 32`，将生成值作为独立的 `MUGONZEI_ADMIN_TOKEN` 保存到服务端配置和你的密码管理器中。生产还需要设置 `MUGONZEI_ADMIN_HOST`，值为供管理使用的准确主机名，可带端口，例如 `api.example.com`。服务启动时读取这两个值。
3. 使用 HTTPS。已有 API 域名反向代理到后台时，可直接在该域名访问 `/admin/`。若使用官网域名，请把 `/admin` 与 `/admin/*` 一并代理给服务端，参考[网站 Caddy 配置](../website/Caddyfile.example)。`MUGONZEI_TRUSTED_PROXIES` 填实际反向代理的 IP，Kestrel 只监听回环或受控内部地址。
4. 重启服务，使用配置的 HTTPS 域名访问 `/admin/` 并输入管理口令。一次登录有效 30 分钟。点「退出管理」可立即结束本次登录。轮换管理员口令时更新受保护配置并重启，所有旧会话都会结束。清空管理口令并重启可关闭后台。

## 日常操作

- **付款优惠码**。选择套餐，填写折后价、爱发电折扣方案 ID 和有效期。确认前核对积分数和价格，生成后复制口令。活动可在列表中停用。爱发电收款方案需要由运营者提前配置，参考[优惠码说明](COUPONS.md)。
- **积分兑换码**。填写每个码的积分、数量和有效期。只发一张时，可以自选一个中文或英文口令；留空或批量发放时会生成随机码。发给群友时选择「共享码 · 每个账号可领一次」：所有账号使用同一口令，各自领取面额，没有总人数上限。私发单人券时选「一次性码 · 仅一人可领」。列表可查看领取次数；旧单人码可改为共享，之前领过的账号不会再得积分。停用共享码会阻止新领取，已入账积分保留。明文口令只在生成时显示。
- **连接中断**。在页面按原操作重试时会复用请求编号。同一请求只发放一次，重新读取列表只能看到活动或兑换码的记录。若错过首次明文，请先核对列表，需要替换时先停用未使用的旧码，再发新码。

日常创建和停用可以在线完成，客户在下一次核价或兑换时就会看到结果。已创建的付款订单仍按建单时确认的金额结算。
